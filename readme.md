# English Tenses Academy

> An interactive and visually rich platform designed to make English tenses easier to understand.

English Tenses Academy is a modern educational web project that helps learners understand all **12 English tenses** through visual explanations, interactive timelines, grammar structures, examples, animations, and smart search functionality.

The goal of this project is not just to explain grammar with text, but to make abstract tense concepts easier to understand through interactive visual learning.

---

## Features

### 12 English Tenses

The platform includes detailed lessons for all major English tenses:

#### Present Tenses

- Simple Present
- Present Continuous
- Present Perfect
- Present Perfect Continuous

#### Past Tenses

- Simple Past
- Past Continuous
- Past Perfect
- Past Perfect Continuous

#### Future Tenses

- Simple Future
- Future Continuous
- Future Perfect
- Future Perfect Continuous

---

## Interactive Learning System

Each tense includes multiple learning layers designed to explain the concept from different perspectives.

### Introduction

A clear introduction explaining the meaning and purpose of the tense.

### Visual Timeline

Interactive timeline visualizations help learners understand:

> When does the action happen?

The timeline visually represents the relationship between:

- Past
- Present
- Future
- Ongoing actions
- Completed actions
- Duration

---

### See It in Action

Each tense includes a dedicated mini educational animation.

Instead of only reading about grammar rules, learners can visually observe how the tense concept behaves.

For example:

- Repeated actions
- Ongoing actions
- Completed actions
- Actions connected to the present
- Actions completed before another event
- Continuous duration
